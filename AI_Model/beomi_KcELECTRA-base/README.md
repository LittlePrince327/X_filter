# KcELECTRA 비교 실험 안내

이 폴더는 X-filter 프로젝트에서 수행한 KcELECTRA 비교 실험을 보관합니다. KcELECTRA는 최종 취업 문서 기준 모델이 아니라 KcBERT 선정 과정에서 비교한 후보 모델로 구분합니다.

저장된 노트북에는 데이터 구성·배치 크기·실행 시점이 서로 다른 중간 결과가 포함될 수 있습니다. 따라서 이 폴더의 개별 출력값을 KcBERT 최종 기록과 합치거나 동일 평가 결과로 해석하지 않습니다.

## 자료별로 남아 있는 KcELECTRA 기록

- 초기 포트폴리오: Accuracy 93%
- Drive 빅데이터분석정의서: Accuracy 0.8529, Precision 0.7059, Recall 0.8276, F1 0.7619
- GitHub 중간 실행 출력: Accuracy 0.4511, Precision 0.2034, Recall 0.4511, F1 0.2804

서로 다른 조건의 기록이므로 재현 가능한 단일 최종 성능으로 사용하지 않습니다. 공개 취업 자료의 기준은 `docs/XFILTER_METRICS.md`를 따릅니다.
